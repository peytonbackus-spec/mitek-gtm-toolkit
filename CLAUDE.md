Public GitHub repo (peytonbackus-spec/mitek-gtm-toolkit). See README.md for purpose and layout.

## Rules
- Public repo: never commit secrets, API keys, client or prospect data, or anything under a `_private/` folder.
- Never commit or push unless I ask for it in that message.
- Run the tests (`make test` or `pytest`) before proposing a change as done.
- Python venvs (`.venv/`) and `outputs/` are local and ignored; don't add them.
- `gtm_strategy_ops/panel_brief/_private/` is confidential interview material: never quote it into outputs, never un-ignore it, never commit it.
- `gtm_strategy_ops/panel_brief/` as a whole stays uncommitted unless I explicitly say otherwise.
